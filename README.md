# DataBeagle: an app for animal shelters

* **Autor:** Dora Kovačević
* **Datum:** svibanj 2026.

## O projektu
Ovaj projekt pokriva proces evolutivnog razvoja softvera za sklonište za životinje, koji će omogućiti rad s podacima o životinjama u skloništu, evidenciju donacija i troškova, evidenciju rada volontera i unos podataka o udomiteljima i udomljavanju.  
Projekt u mapi Documentation sadrži detaljnu specifikaciju softverskih zahtjeva i izradu nekoliko vrsta dijagrama prema UML-u, dok se u mapi Software nalazi implementacija ključnih funkcionalnih zahtjeva: manipulacija podatcima o životinjama te generiranje izvještaja.  

## Korištene tehnologije
* **C# .NET** – izrada korisničkog sučelja i backend
* **SQL** – za rad s bazom podataka
